# Teste Técnico: Desenvolvedor Web - Grupo SOITIC

Este repositório contém a estrutura básica para o teste técnico de Desenvolvedor Web no Grupo SOITIC.

## Objetivo

O objetivo deste teste é avaliar suas habilidades em desenvolvimento web, incluindo lógica de programação, arquitetura de frontend e design de interface de usuário. Você deverá desenvolver um protótipo funcional de um **Dashboard de Agendamentos e Gestão de Pacientes** para uma clínica médica, utilizando dados simulados.

## Estrutura do Repositório

- `data/appointments.json`: Arquivo JSON contendo os dados simulados de agendamentos.
- `src/`: Pasta onde você deve colocar o código-fonte da sua aplicação (tecnologia escolhida).

## Requisitos

Consulte o documento de instruções completo para obter todos os detalhes sobre os requisitos técnicos e de design específicos para este teste.

### Principais Áreas Avaliadas:

*   **Lógica de Programação e Manipulação de Dados:** Capacidade de processar, agregar, filtrar e ordenar dados de forma eficiente.
*   **Arquitetura de Frontend:** Organização do código, modularidade, componentização e uso de boas práticas.
*   **UX/UI e Responsividade:** Qualidade da interface, usabilidade, interatividade e adaptação a diferentes dispositivos.
*   **Qualidade do Código:** Legibilidade, manutenibilidade e aderência a padrões de codificação.

## Como Entregar

1.  Crie um repositório público no GitHub ou GitLab.
2.  Suba o seu código para o repositório.
3.  Certifique-se de que o seu `README.md` esteja atualizado com instruções claras sobre como rodar o projeto localmente, as principais decisões de arquitetura e as tecnologias escolhidas, justificando-as.

Boa sorte! Estamos ansiosos para ver sua solução e como você pode contribuir para a inovação no Grupo SOITIC.
