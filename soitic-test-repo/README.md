# Teste Técnico: Desenvolvedor Web Júnior - Grupo SOITIC

Este repositório contém a estrutura básica para o teste técnico de Desenvolvedor Web Júnior no Grupo SOITIC.

## Objetivo

O objetivo deste teste é criar uma aplicação web simples que exiba uma lista de agendamentos de uma clínica médica a partir de um arquivo JSON.

## Estrutura do Repositório

- `data/appointments.json`: Arquivo JSON contendo os dados simulados de agendamentos.
- `src/`: Pasta onde você deve colocar o código-fonte da sua aplicação (HTML, CSS, JS).

## Requisitos

Consulte o documento de instruções completo para obter todos os detalhes sobre os requisitos técnicos e de design.

### Principais Funcionalidades:
1. Carregar e exibir os dados do arquivo `data/appointments.json`.
2. Mostrar o número total de agendamentos.
3. Implementar um filtro para exibir apenas agendamentos com status 'confirmado'.
4. Estilizar a interface de forma clara e organizada.

## Como Entregar

1. Crie um repositório público no GitHub ou GitLab.
2. Suba o seu código para o repositório.
3. Certifique-se de que o seu `README.md` contenha instruções claras sobre como rodar o projeto localmente.

Boa sorte!
