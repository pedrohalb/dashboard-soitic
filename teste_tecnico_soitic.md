# Teste Técnico: Desenvolvedor Web Júnior - Grupo SOITIC

## Introdução

Bem-vindo ao teste técnico para a vaga de Desenvolvedor Web Júnior no Grupo SOITIC. Somos uma empresa com mais de 40 anos de história, focada em soluções de tecnologia, educação e comunicação [1]. Buscamos talentos que demonstrem paixão por programação, uma base sólida em lógica e interesse em construir interfaces de usuário intuitivas.

Este teste foi elaborado para avaliar seus conhecimentos fundamentais em desenvolvimento web, sua capacidade de resolver problemas básicos e sua atenção aos detalhes na construção de uma interface.

---

## O Desafio: Listagem Simples de Agendamentos

Seu desafio é criar uma aplicação web simples que exiba uma lista de agendamentos de uma clínica médica. Você receberá um arquivo JSON com dados simulados de agendamentos.

O objetivo é demonstrar sua capacidade de ler dados, processá-los minimamente e apresentá-los de forma clara em uma interface web.

### Parte 1: Lógica e Exibição de Dados (Peso: 60%)

Você receberá um arquivo `appointments.json` contendo uma lista de agendamentos. Cada agendamento terá informações como: ID, nome do paciente, data/hora da consulta e status (confirmado, pendente, cancelado).

**Requisitos Técnicos:**

1.  **Carregamento de Dados:** Leia o conteúdo do arquivo `appointments.json` e carregue-o em sua aplicação.
2.  **Listagem:** Exiba todos os agendamentos em uma lista ou tabela na página.
3.  **Contagem Simples:** Calcule e exiba o número total de agendamentos.
4.  **Filtro Básico:** Implemente um filtro simples que permita ao usuário visualizar apenas os agendamentos com status 'confirmado'.

### Parte 2: UX/UI Básica e Implementação de Interface (Peso: 40%)

Com base nos dados carregados e processados na Parte 1, construa a interface da aplicação.

**Requisitos de Design e Implementação:**

1.  **Estrutura HTML:** Crie uma estrutura HTML semântica para a página.
2.  **Estilização Básica:** Utilize CSS para estilizar a lista/tabela de agendamentos, tornando-a legível e organizada. Diferencie visualmente os status dos agendamentos (ex: cores diferentes para 'confirmado', 'pendente', 'cancelado').
3.  **Botão de Filtro:** Adicione um botão ou checkbox para ativar/desativar o filtro de agendamentos 'confirmados'.
4.  **Responsividade (Básico):** A página deve ser utilizável em telas de diferentes tamanhos, sem quebrar o layout principal (não é necessário um design complexo, apenas que seja funcional em dispositivos móveis básicos).

## Critérios de Avaliação

Para a vaga de Desenvolvedor Júnior, focaremos nos fundamentos e na clareza da sua solução.

| Critério | Descrição |
| :--- | :--- |
| **Lógica de Programação** | Correta leitura e manipulação dos dados, implementação funcional do filtro e contagem. |
| **Estrutura do Código** | Organização básica do código (HTML, CSS, JavaScript), legibilidade e uso de boas práticas de nomenclatura. |
| **Implementação da Interface** | Estrutura HTML semântica, estilização funcional e clara, e usabilidade básica do filtro. |
| **Atenção aos Detalhes** | Cuidado com a apresentação visual e a experiência básica do usuário. |

## Instruções de Entrega

1.  **Stack Tecnológico:** Você pode usar HTML, CSS e JavaScript puro. O uso de bibliotecas leves (como jQuery) é permitido, mas não obrigatório. Frameworks como React, Vue ou Angular não são esperados para este teste, mas se você tiver experiência e quiser usá-los de forma simples, pode fazê-lo.
2.  **Repositório:** O código deve ser hospedado em um repositório público no GitHub ou GitLab.
3.  **Documentação (README):** O repositório deve conter um arquivo `README.md` detalhado, explicando:
    *   Como rodar o projeto localmente.
    *   As principais decisões tomadas (ex: como você carregou o JSON, por que escolheu certas cores).

### Tempo Estimado de Conclusão

Para um desenvolvedor de nível Júnior, estimamos que este teste exija entre **4 a 6 horas** de dedicação para ser concluído, permitindo tempo para pesquisa e implementação dos requisitos básicos.
